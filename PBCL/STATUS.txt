WHAT IS THIS?
--------------------------------------------------------------
A lightweight calibration layer for ranking confidence in web
data before heavy semantic verification.

It does NOT prove truth.
It does NOT derive truth from primality.
It does NOT replace semantic reasoning.

It DOES:
  - Detect tampering via SHA3-256 fingerprints
  - Remove duplicates
  - Measure source agreement
  - Match against a registry of verified anchors
  - Rank confidence via explicit weight function
  - Issue 3-state decision: ACCEPT / REVIEW / REJECT

--------------------------------------------------------------
KEY NUMBERS
--------------------------------------------------------------
Weight Formula : W = 0.25*A + 0.50*T - 0.50*C + 0.25*D
Thresholds     : ACCEPT >= 0.85 | REVIEW >= 0.50 | REJECT < 0.50
Latency        : ~0.079 ms per claim
Real Accuracy  : ~50-60% on general data (not 100%)
