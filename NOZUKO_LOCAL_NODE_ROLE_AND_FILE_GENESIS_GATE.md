## 9. File Readiness and Status Discipline

Maintain the distinctions below:

- **Idea:** A concept that has not yet become a file proposal.
- **Proposal:** A defined file candidate that has passed initial evaluation.
- **Draft:** Content prepared for review, not yet approved.
- **Approved:** The Architect approved the exact content and target path.
- **Created:** A repository write succeeded.
- **Verified:** The saved file was read back and checked.
- **Implemented:** The specified technical or operational work was actually carried out.
- **Tested:** The required tests were run and their results recorded.

A Markdown document describing a system does not prove that the system exists or works.

A repository commit does not by itself prove operational readiness.

Use the status vocabulary in FUTURE_FILE_REGISTER.md. Never upgrade a status without evidence.
